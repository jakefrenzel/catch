# Roadmap

What's next, from the plan [How Catch Helps People Finish What They Start](https://claude.ai/artifact/LFugKi3d5jTte38QXarach),
which explains the research behind each item. Tick each one when it's merged.

## 1.2: the progress update

- [x] The evening wrap-up shows what got done today, and the project closest to done (#17)
- [ ] Monthly Someday review: once a month, a gentle reminder to look through Someday and pull something into Now
- [ ] Flag stalled projects: a project with no progress in 2 weeks comes back as Up first, "Untouched for 2 weeks"

## Plan for next (more impact, more work)

- [ ] Weekly progress summary: a "New week" card on Mondays with what got done last week, offering something from Someday
- [ ] Split stuck items: something carried over 3 or more nights suggests a smaller first step, or Someday
- [ ] Ask when you'll do it: sorting into Now asks "When will you do this?" ("after lunch"), an if-then plan

## Quick extras

- [ ] "Done" vs "to go" on projects: "2 done" while a project is new, "2 to go" once it's well underway
- [ ] Daily Inbox nudge ("3 ideas to sort"), in one daily summary rather than separate notifications
- [ ] Say where a capture went: "Saved to Later, Friday 3 PM"

## Later

- [ ] Suggest places ("when you get home") before clock times for reminders
- [ ] Learn from reminders that keep being ignored, and suggest a better time
- [ ] Ask for a rough task size (5 min, 30 min, an hour or more)

## Rules every feature follows

From the plan's design principles: capturing never requires deciding; one next action at a time;
cues over clocks; few, worthwhile interruptions; celebrate, never punish (no streaks that reset,
no "0 done"); letting go is a valid outcome; close every day.
